# Сервис уведомлений

Автор: Швырёв Максим

## Что делает программа

Реализация сервиса отправки.
2 способа: Email и Push

## Как запустить

1) Выполнение из папки student
2) Версия Go - 1.22 и новее
3) Запуск программы - go run ./cmd/notify
4) Запуск тестов - go test ./...

## Проверенные случаи

Успешная отправка - сообщение доставляется через Email и Push

Пустое сообщение - возвращается ошибка ErrEmptyMessage без изменения истории

Отсутствие настройки - возвращается SendError и сообщение не отправляется

Паника канала - SafeDispatch перехватывает панику, следующий Push-канал получает сообщение «Заказ готов».

## Обработка ошибок

Объясните, чем отличаются Dispatch и SafeDispatch. Покажите, где используются errors.Is и errors.As, и почему recover находится вокруг отдельного вызова.
Dispatch прекращает отправку при первой ошибке, а SafeDispatch продолжает работу и собирает ошибки

errors.Is используется для проверки известных ошибок, а errors.As используется для получения ошибки типа SendError

recover находится внутри SafeSend, чтобы паника одного канала не прерывала отправку через остальные
